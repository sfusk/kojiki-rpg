# RPG古事記

古事記をたどるドット絵RPG。全8章をめぐり、各地の「かたりべ」からクイズに答えて「ちえのたま」を集め、8個そろうと真エンディングが見られる。

## 起動

```
npm run dev
```

`http://localhost:8090/` を開く。

開発サーバーは `Cache-Control: no-store` を返すため、コードを直しても古いJSモジュールが
ブラウザに残らない（`python -m http.server` ではキャッシュが残り、修正が反映されない事故が起きた）。

## 操作

- 矢印キー：移動
- Z / Enter：決定・はなす（メッセージ送り）
- X / Esc：メニューを開く（つよさ・たびのしょ・とじる）

## テスト

```
npm test
```
